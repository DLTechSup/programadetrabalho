# Catálogo + Administração (Calçados 24h)

Site estático com o catálogo de fotos das marcas e referências da loja (`index.html`) e a área
de administração para gerenciar esse catálogo (`admin.html`). Conecta a um painel remoto cujo
endereço fica salvo em `servidor.json`.

Abra `index.html` direto no navegador (ou hospede como site estático) para usar.
