Fotos limpas, sem código opcional

Como funciona

  1. Escolha a marca (ou digite uma nova) e a referência.
  2. Coloque as fotos com código e, se quiser, as limpas.
  3. Clique em salvar. As fotos vão para LANÇAMENTOS › MARCA › REFERÊNCIA (as com código na subpasta “FOTOS COM CODIGOS”).

O site mostra as fotos com código. Se a referência não tiver, mostra as limpas.
