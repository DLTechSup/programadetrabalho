# Separador de Fotos

Separa as fotos de calçados por marca e referência, lendo a etiqueta da caixa (OCR) e
organizando tudo em pastas `Marca - Referência`.

```
python separador.py              # abre a janela para escolher a pasta
python separador.py C:\fotos     # roda direto, sem janela
```

Programa em Python (desktop). Faz parte da Central DLTechSup como código de origem --
ainda não foi portado para dentro do app principal.
