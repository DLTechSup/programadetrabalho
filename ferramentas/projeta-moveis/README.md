# Projeta Móveis

Programa para Windows (React + Electron) que gera **projetos executivos de marcenaria** — desenho técnico cotado, plano de
corte, relação de materiais e orçamento — a partir das medidas digitadas, com preview ao vivo.

- **`app/`** — o programa atual (React + TypeScript + Electron). Veja [`app/README.md`](app/README.md).
- **`PLANO.md`** — especificação original do projeto.
- **`legado-python/`** — primeira versão (Python/PySide6), mantida só como referência.

## Baixar o instalador
Na página **Releases** do repositório fica o `Instalador-Projeta-Moveis-*.exe` (gerado automaticamente a cada atualização do
código). Também há a versão portátil, que não precisa instalar.
